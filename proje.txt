2. Veri Kalitesi — Data Quality
Bence uygulamanın esas değer üreten ekranı burası.
Kullanıcı hiçbir Python kodu yazmadan verisindeki problemleri görebilmeli.
Üst tarafta bir Veri Kalite Skoru bulunabilir:
Veri Kalitesi
78 / 100
Ama skorun nasıl hesaplandığı açık olmalı; rastgele bir puan olmamalı.
Örneğin şu kontrollerden oluşturulabilir:
Eksik değer oranı
Duplicate oranı
Veri tipi problemleri

Her sütun için:
SütunEksikOranAge125%4.3Torque40%1.4City162%5.6

Missing Values Bar Chart
olmalı.
Duplicate analizi
Gösterilecek:
Toplam tekrar eden kayıt: 42
Duplicate oranı: %0.42
İstenirse duplicate kayıtların birkaç örneği gösterilebilir.
Veri tipi kontrolü
Örneğin:
Age          object       ⚠ Sayısal olabilir
Torque       float64      ✓
Date         object       ⚠ Tarih olabilir
Type         object       ✓
Sistem otomatik tahminde bulunabilir ama:
“Bu sütunu kesinlikle integer yap”
demek yerine:
“Sayısal veri içeriyor olabilir.”
şeklinde öneri vermeli.

Cardinality
Kategorik sütun için:
